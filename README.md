# Моя вахта

**Моя вахта** — мобильный интерфейс для планирования вахтового графика, учёта выплат, заметок и общения с коллегами.

## Открыть приложение

- [Моя вахта — GitHub Pages](https://crossdoomdev.github.io/my_vahta/)
- Для запуска из исходников откройте `index.html` в браузере.

## Разделы

- **Главная.** Текущий статус, начало и окончание вахты, отработанные и оставшиеся дни, быстрый доступ к разделам.
- **Календарь.** Рабочие дни, межвахтовый отдых, отпуск, профессиональные праздники и отмеченные выплаты.
- **Финансы.** Авансы, зарплаты и премии, история выплат по датам.
- **Сообщения.** Список бесед, сообщения, счётчик непрочитанных.
- **Друзья.** Поиск, фильтр статусов, анкеты, профессии, организации, сведения о вахтах.
- **Заметки.** Записи, списки дел и планы.
- **Организация.** Четыре критерия оценки: зарплата, бытовые условия, руководство и график вахты; текстовый отзыв.
- **Конфиденциальность.** Настройка видимости статуса, обратного отсчёта, календаря, организации, рейтинга, комментария и финансов. По умолчанию финансовая история закрыта.
- **Статистика.** График дней вахты и учёт записанных выплат.
- **Настройки и данные.** Импорт, экспорт резервной копии и сброс данных.

## Структура проекта

- `index.html` — точка входа и навигация;
- `styles.css` — основные стили;
- `friends.css` — список друзей, анкеты, статусы и финансовые карточки;
- `app.js` — состояние, обработчики и экраны;
- `assets/` — иллюстрации, иконки статусов и портреты.

## Разработка

Код организован как статическое веб-приложение на HTML, CSS и JavaScript. Изменения интерфейса публикуются из ветки `main`. Все тексты экрана предназначены для пользовательского интерфейса, а не для технических пояснений о ходе разработки.

# Моя вахта — интерактивный HTML-прототип

Мобильный прототип Android-приложения для работников вахтовым методом. Разрабатывается отдельно от серверной части, чтобы сначала проверить дизайн и сценарии.

## Запуск

Откройте `index.html` в браузере или включите GitHub Pages для ветки `main`, папка `/ (root)`. Доступный адрес после включения Pages: `https://crossdoomdev.github.io/my_vahta/`.

Локально с HTTP-сервером (необязательно): `python -m http.server 8000`, затем `http://localhost:8000/`.

Не используются сборщики, npm, базы данных и сторонние JavaScript-библиотеки. Внешний доступ к интернету для демонстрационного интерфейса не требуется.

## Реализовано в прототипе

- Главная страница с иллюстрацией промплощадки, текущим статусом, началом и концом вахты, отработанными и оставшимися днями.
- Статус **на вахте / на межвахте** рассчитывается по указанным датам; **отпуск** включается вручную.
- Календарь вахт, местных финансовых записей и некоторых профессиональных праздников России; фильтр профессий находится в разделе «Ещё → Профессиональные праздники».
- Финансы: ручное внесение, изменение и удаление **аванса, зарплаты, премии** и иной выплаты; просмотр по месяцам. Суммы выплат не показываются друзьям.
- Заметки и списки дел с чекбоксами.
- Организация: название, сфера работы, регион, оценки по критериям, свободный комментарий.
- Конфиденциальность: отдельные разрешения на статус, обратный отсчёт, календарь, организацию, рейтинг и комментарий.
- Социальный **макет**: отдельный экран «Друзья» с иллюстрированными статусами «На вахте», «Межвахта», «Отпуск» и «Не в сети», поиском по друзьям и фильтром по статусу.\n- По нажатию на друга открывается полноэкранная демонстрационная анкета: профессия, организация, график, регион, стаж, пример оценки работодателя, текущий статус и кнопка «Написать». Анкета не раскрывает суммы выплат.\n- Вкладка «Сообщения» находится отдельно в нижней навигации: локальные чаты со счётчиком непрочитанного. Колокольчик уведомлений расположен сверху.
- Дополнительные экраны: статистика, профиль, настройки, просмотр уведомлений.
- Сохранение данных в `localStorage`, импорт/экспорт JSON и сброс демоданных.

## Ограничения

**Это не работающая социальная сеть.** Нет регистрации, серверной синхронизации, настоящих запросов дружбы, доставки сообщений и push-уведомлений. Локальные «друзья» и «сообщения» — демонстрация будущего интерфейса, они никому не отправляются. Сведения в анкетах вымышленные. Для реальных профилей потребуется учитывать персональные настройки видимости каждого владельца профиля на сервере. Разрешения приватности сейчас влияют только на локальный предпросмотр. Для реальных пользователей потребуются серверная авторизация и проверка доступа на стороне API. Данные выплат и заметок находятся в локальном хранилище браузера, поэтому важна резервная копия JSON.

Справочник праздников пока содержит только несколько российских профессиональных дат. Годовая статистика считает дни по **одной** сохранённой вахте; история нескольких вахт — отдельный этап.

## Структура

- `index.html` — HTML-каркас приложения с SVG-иконками и нижней навигацией.
- `styles.css` — мобильный интерфейс, адаптивность, тёмная палитра.\n- `friends.css` — оформление списка друзей, статусов и анкеты.
- `app.js` — экраны, логика, демонстрационные данные, местное хранение.
- `assets/shift-sunset.svg` — оригинальная иллюстрация главного экрана.
- `assets/company-site.svg` — оригинальная иллюстрация организации.
- `assets/helmet.svg` — иконка приложения.\n- `assets/status-*.svg` — отдельные оригинальные изображения статусов.\n- `assets/avatar-*.svg` — оригинальные рисованные портреты для демонстрационных анкет.
